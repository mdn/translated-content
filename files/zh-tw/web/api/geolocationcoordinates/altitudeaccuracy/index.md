{{domxref("GeolocationCoordinates")}} 介面的 **`altitudeAccuracy`** 唯讀屬性是一個正的 `double` 值，表示 `altitude` 在 68% 信賴水準下的準確度（以公尺為單位）。如果實作不支援測量高度，則此值為 `null`。

## 值

一個正的 `double` 值，表示 `altitude` 在 68% 信賴水準下的準確度（以公尺為單位）。
