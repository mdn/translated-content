## Multimedia

- [Distribución de audio y video](/es/docs/Web/Media/Guides/Audio_and_video_delivery)
  - : Es posible distribuir audio y video en la web de varias maneras, desde archivos multimedia "estáticos" hasta transmisiones en vivo adaptativas. Este artículo sirve como punto de partida para explorar los distintos mecanismos de distribución de contenido multimedia en la web y su compatibilidad con los navegadores más populares.
- [Manipulación de audio y video](/es/docs/Web/Media/Guides/Audio_and_video_manipulation)
  - : Una de las grandes ventajas de la web es la posibilidad de combinar tecnologías para crear nuevas formas de contenido. Gracias a la compatibilidad nativa con audio y video en el navegador, podemos integrar estos flujos de datos con tecnologías como {{htmlelement("canvas")}}, [WebGL](/es/docs/Web/API/WebGL_API) o la [Web Audio API](/es/docs/Web/API/Web_Audio_API) para modificar el audio y el video directamente. Por ejemplo, podemos añadir efectos de reverberación o compresión al audio, o filtros de escala de grises o sepia al video. Este artículo sirve de referencia para explicar lo que necesitas hacer.

## APIs

- [Uso de objetos FormData](/es/docs/Web/API/XMLHttpRequest_API/Using_FormData_Objects)
  - : El objeto [`FormData`](/es/docs/Web/API/FormData) te permite reunir un conjunto de pares clave/valor para enviarlos con {{domxref("Window/fetch", "fetch()")}}. Aunque está diseñado principalmente para enviar datos de formularios, también puede utilizarse de forma independiente para transmitir información estructurada mediante claves. La transmisión usa el mismo formato que usaría el método `submit()` del formulario si el tipo de codificación del formulario estuviera establecido en "multipart/form-data".
- [Aplicaciones web progresivas](/es/docs/Web/Progressive_web_apps)
  - : Las aplicaciones web progresivas (PWA) usan API web modernas junto con la estrategia tradicional de mejora progresiva para crear aplicaciones web multiplataforma. Estas aplicaciones funcionan en cualquier lugar y ofrecen varias funcionalidades que les dan las mismas ventajas de experiencia de usuario que las aplicaciones nativas. Esta serie de guías contiene todo lo que necesitas saber sobre las PWA.
- [Análisis y serialización de XML](/es/docs/Web/XML/Guides/Parsing_and_serializing_XML)
  - : La plataforma web ofrece distintos métodos para analizar y serializar XML, cada uno con sus ventajas e inconvenientes.
