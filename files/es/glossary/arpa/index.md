**.arpa** (área de parámetros de dirección y enrutamiento) es un {{glossary("TLD","dominio de nivel superior")}} en el Sistema de Nombres de Dominio (DNS) que se usa para fines de infraestructura de Internet, sobre todo para la búsqueda inversa de DNS (es decir, encontrar el {{glossary('domain name', 'nombre de dominio')}} que corresponde a una {{glossary("IP address", "dirección IP")}} determinada).

El nombre proviene de **ARPA**, conocida actualmente como [DARPA](https://en.wikipedia.org/wiki/DARPA), la Agencia de Proyectos de Investigación Avanzados de Defensa. A DARPA se le atribuye el desarrollo de los precursores de Internet ({{glossary("ARPANET")}}), el GPS, la inteligencia artificial y la realidad virtual. Originalmente, el dominio solo iba a cumplir una función temporal para facilitar la asignación sistemática de nombres a los equipos de ARPANET, pero no se llegó a eliminar cuando se autorizaron sus usos en la infraestructura. Por eso, el nombre de dominio ARPA es un retroacrónimo de "Address and Routing Parameter Area".

El {{glossary("TLD")}} se diseñó en DARPA cuando esta todavía se llamaba ARPA, de ahí el nombre de dominio `.arpa`.

Entre los dominios `.arpa` más destacados están `in-addr.arpa` e `ip6.arpa`, que proporcionan espacios de nombres para la búsqueda inversa de DNS de direcciones IPv4 e IPv6, respectivamente.
