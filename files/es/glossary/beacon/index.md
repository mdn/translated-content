Un **beacon** web es un pequeño objeto, como un GIF de 1 píxel, incrustado en el marcado y utilizado para enviar información de vuelta al servidor web o a servidores de terceros. Por lo general, estos elementos se incluyen para proporcionar información sobre el usuario con fines estadísticos. Es habitual encontrarlos dentro de scripts de terceros que recopilan datos de usuarios, métricas de rendimiento e informes de errores.

Existe un [borrador de la especificación Beacon del W3C](https://w3c.github.io/beacon/) para estandarizar el beacon como una interfaz para transferir de forma asíncrona datos HTTP desde el agente de usuario a un servidor web antes de la carga de la página, sin un impacto negativo en el rendimiento.
