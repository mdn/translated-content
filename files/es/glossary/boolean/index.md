En informática, un **booleano** es un tipo de datos lógico que solo puede tener los valores `true` o `false`.

Por ejemplo, en JavaScript, las condiciones booleanas se suelen usar para decidir qué secciones de código se ejecutan (como en las [sentencias if](/es/docs/Web/JavaScript/Reference/Statements/if...else)) o se repiten (como en los [bucles for](/es/docs/Web/JavaScript/Reference/Statements/for)).

A continuación se muestra un pseudocódigo de JavaScript (no es código ejecutable real) que ilustra este concepto.

```js-nolint
/* Sentencia if de JavaScript */
if (boolean conditional) {
  // código que se ejecuta si la condición es true
}

if (boolean conditional) {
  console.log("la condición booleana se evaluó como true");
} else {
  console.log("la condición booleana se evaluó como false");
}

/* Bucle for de JavaScript */
for (control variable; boolean conditional; counter) {
  // código que se ejecuta repetidamente si la condición es true
}
```

El valor booleano debe su nombre al matemático inglés [George Boole](https://en.wikipedia.org/wiki/George_Boole), pionero en el campo de la lógica matemática.
