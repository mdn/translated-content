Una **dirección IP** es un número que se usa para identificar de forma única cada dispositivo de una red IP.

_IP_ significa _Internet Protocol_ (protocolo de Internet), que es la [capa de protocolo](https://docs.oracle.com/cd/E19683-01/806-4075/ipov-7/index.html) con la que está asociada la dirección.

Por lo general, «dirección IP» todavía se refiere a las direcciones IPv4 de 32 bits, hasta que IPv6 se implemente de forma más amplia.
