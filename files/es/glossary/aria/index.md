**ARIA** (_{{Glossary("Accessibility", "Accessible")}} Rich {{glossary("Internet")}} Applications_) es una especificación del {{Glossary("W3C")}} desarrollada por la {{Glossary("WAI")}} para que el contenido y las aplicaciones web sean más accesibles para las personas con discapacidad. Resulta especialmente útil para el contenido dinámico y los controles avanzados de interfaz de usuario desarrollados con HTML, JavaScript y tecnologías relacionadas.

Por ejemplo, la especificación te permite añadir el atributo `role="alert"` a una {{glossary("tag", "etiqueta")}} {{HTMLElement("p")}} para notificar a un usuario con discapacidad visual que la información es importante y urgente (algo que, de otro modo, podrías transmitir con el color del texto).
