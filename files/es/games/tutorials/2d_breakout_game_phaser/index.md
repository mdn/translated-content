En este tutorial paso a paso creamos un juego sencillo para móviles, **MDN Breakout**, escrito en JavaScript con el framework [Phaser](https://phaser.io/).

Cada paso tiene ejemplos en vivo editables con los que puedes jugar, para que veas cómo deberían quedar las etapas intermedias. Aprenderás los fundamentos del uso del framework Phaser para implementar mecánicas de juego básicas, como el renderizado y movimiento de imágenes, la detección de colisiones, los mecanismos de control, las funciones auxiliares propias del framework, las animaciones y tweens, y los estados de victoria y derrota.

Para aprovechar al máximo esta serie de artículos, deberías tener ya conocimientos de [JavaScript](/es/docs/Learn_web_development/Getting_started/Your_first_website/Adding_interactivity) de nivel básico a intermedio. Después de seguir este tutorial, deberías poder crear tus propios juegos web básicos con Phaser.

![Pantalla del juego MDN Breakout creado con Phaser, en la que usas la paleta para hacer rebotar la pelota y destruir el muro de ladrillos, mientras se llevan los puntos y las vidas.](mdn-breakout-phaser.png)

> [!NOTE]
> Esta guía tiene una guía hermana: [Juego Breakout 2D con JavaScript puro](/es/docs/Games/Tutorials/2D_breakout_game_pure_JavaScript). Las dos siguen prácticamente los mismos pasos y llegan a resultados visualmente idénticos.

Elegimos Phaser para este proyecto porque es compatible con los navegadores, tiene una comunidad activa y un buen conjunto de complementos. Los frameworks aceleran el desarrollo y se encargan de las partes aburridas, para que puedas concentrarte en lo divertido. Sin embargo, los frameworks no siempre son perfectos, así que si ocurre algo inesperado o quieres escribir alguna funcionalidad que el framework no ofrece, necesitarás algunos conocimientos de JavaScript puro.
