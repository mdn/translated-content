**인증**은 일반적으로 어떤 사실이 진짜임을 증명하는 과정입니다. 웹 보안에서는 더 구체적으로, 사용자와 같은 어떤 주체가 주장하는 신원을 확인하는 과정을 말합니다. 인증을 거치면 특정 계정에 로그인하는 것처럼 사용자가 요청한 접근을 허용할지 결정할 수 있습니다.

인증은 보통 사용자가 사용자 식별자와 함께 비밀번호, 일회용 코드, 개인 키로 서명한 어설션(assertion) 같은 {{glossary("credential", "자격 증명")}}을 제시하는 방식으로 이루어집니다. 그러면 시스템은 사용자 식별자와 자격 증명이 서로 연결되어 있는지 확인하여 사용자를 인증할지 결정합니다.

인증 정보의 종류는 '인증 요소'라고도 하며, 흔히 다음 세 가지 범주로 나눕니다.

- 비밀번호처럼 사용자가 알고 있는 것
- 휴대폰처럼 사용자가 가지고 있는 것
- 지문처럼 사용자 자신의 일부인 것

{{glossary("Multi-factor authentication", "다중 인증")}}(MFA) 시스템은 사용자에게 두 가지 이상의 요소를 요구합니다. 예를 들어 비밀번호와 함께 사용자 휴대폰의 인증 앱으로 생성한 일회용 코드를 요구할 수 있습니다.
