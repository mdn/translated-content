Une **rangée de grille** est une piste horizontale dans une [grille CSS](/fr/docs/Web/CSS/Guides/Grid_layout), qui se situe dans l'espace entre deux lignes de grille horizontales. Elle est définie par la propriété {{CSSxRef("grid-template-rows")}} ou les propriétés raccourcies {{CSSxRef("grid")}} ou {{CSSxRef("grid-template")}}.

De plus, des rangées peuvent être créées dans la _grille implicite_ lorsque les éléments sont placés en dehors des rangées créées dans la _grille explicite_. Ces rangées sont automatiquement dimensionnées par défaut, ou peuvent avoir une taille définie avec la propriété {{CSSxRef("grid-auto-rows")}}.

Lorsque vous travaillez avec l'alignement dans [une grille](/fr/docs/Web/CSS/Guides/Grid_layout), l'axe le long duquel les rangées sont exécutées est appelé _l'axe de ligne ou de rangée_.
