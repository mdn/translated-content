Un **type MIME** (désormais correctement appelé «&nbsp;media type&nbsp;», mais aussi parfois «&nbsp;content type&nbsp;») est une chaîne de caractères envoyée avec un fichier pour en indiquer le type (par exemple, un fichier sonore est étiqueté `audio/ogg` ou un fichier graphique `image/png`).

Il répond au même objectif que les extensions de fichiers traditionnellement utilisées sous Windows.
Le nom vient de la norme {{Glossary("MIME")}} initialement utilisée dans les courriels.
