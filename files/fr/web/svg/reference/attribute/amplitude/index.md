L'attribut **`amplitude`** contrôle l'amplitude de la fonction gamma d'un élément de transfert de composant lorsque son attribut {{SVGAttr("type")}} est `gamma`.

Vous pouvez utiliser cet attribut avec les éléments SVG suivants&nbsp;:

- {{SVGElement("feFuncA")}}
- {{SVGElement("feFuncB")}}
- {{SVGElement("feFuncG")}}
- {{SVGElement("feFuncR")}}
