Le module de **disposition en incise CSS** définit l'alignement et le dimensionnement selon l'axe du bloc du contenu de niveau incise et ajoute un mode de disposition spécial pour les lettrines. Il décrit le modèle de formatage CSS pour un flux d'éléments et de texte à l'intérieur d'un conteneur devant être réparti sur plusieurs lignes.
