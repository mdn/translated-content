{{APIRef("HTML DOM")}}

La propriété **`summary`** de l'interface {{DOMxRef("HTMLTableElement")}} représente la description du tableau.

## Valeur

Une chaîne de caractères.

## Exemples

```js
HTMLTableElement.summary = "Statistiques d'utilisation";
```
