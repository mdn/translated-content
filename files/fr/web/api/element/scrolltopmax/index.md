{{APIRef("DOM")}}{{Non-standard_Header}}

La propriété en lecture seule **`scrollTopMax`** de l'interface {{DOMxRef("Element")}} retourne un nombre représentant le décalage de défilement vertical maximal possible pour l'élément.

## Valeur

Un nombre.

## Spécifications

_Cette propriété ne fait partie d'aucune spécification._

{{Compat}}
