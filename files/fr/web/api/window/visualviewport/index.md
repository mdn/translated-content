{{APIRef("CSSOM view API")}}

La propriété en lecture seule **`visualViewport`** de l'interface {{DOMxRef("Window")}} retourne un objet {{DOMxRef("VisualViewport")}} représentant la zone d'affichage visuelle pour une fenêtre donnée, ou `null` si le document actuel n'est pas entièrement actif.

## Valeur

Un objet {{DOMxRef("VisualViewport")}}.
