{{APIRef("HTML DOM")}}

La propriété **`status`** de l'interface {{DOMxRef("Window")}} était à l'origine destinée à définir le texte dans la barre d'état en bas de la fenêtre du navigateur. Cependant, la norme HTML exige désormais que la définition de `window.status` n'ait aucun effet sur le texte affiché dans la barre d'état.

## Valeur

Une chaîne de caractères.
