{{APIRef("HTML DOM")}}{{Non-standard_Header}}

La méthode **`setResizable()`** de l'interface {{DOMxRef("Window")}} ne fait rien&nbsp;; il s'agit d'une opération sans effet. Elle est uniquement conservée pour la compatibilité avec Netscape 4.x.

## Syntaxe

```js-nolint
setResizable()
```

### Paramètres

Aucun.

### Valeur de retour

Aucune ({{JSxRef("undefined")}}).

## Spécifications

Ne fait partie d'aucune spécification actuelle.
