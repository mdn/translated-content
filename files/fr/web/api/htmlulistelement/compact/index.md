{{APIRef("HTML DOM")}}

La propriété **`compact`** de l'interface {{DOMxRef("HTMLUListElement")}} indique que l'espacement entre les éléments de la liste doit être réduit. La gestion exacte de l'attribut `compact` dépend du navigateur. Au lieu d'utiliser cette propriété, il est recommandé d'utiliser la propriété CSS {{CSSxRef("line-height")}}.

Elle reflète l'attribut [`compact`](/fr/docs/Web/HTML/Reference/Elements/ul#compact) de l'élément HTML {{HTMLElement("ul")}}.

## Valeur

Un booléen.
