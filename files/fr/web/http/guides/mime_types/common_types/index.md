Ce sujet répertorie les types MIME les plus courants avec les types de documents correspondants, classés par leurs extensions courantes.

Les deux types MIME importants suivants sont les types par défaut&nbsp;:

- `text/plain` est la valeur par défaut pour les fichiers texte. Un fichier texte doit être lisible par un humain et ne doit pas contenir de données binaires.
- `application/octet-stream` est la valeur par défaut pour tous les autres cas. Un type de fichier inconnu doit utiliser ce type. Lors de la navigation vers une ressource servie avec ce type, les navigateurs la téléchargent généralement au lieu de l'afficher comme une page, afin d'éviter l'exécution de scripts dans l'origine du site servant la ressource. Cependant, ces ressources peuvent encore être utilisées dans d'autres contextes, y compris être exécutées en tant que JavaScript lorsqu'elles sont référencées par un élément classique {{HTMLElement("script")}} — pour empêcher ce comportement, envoyez [`X-Content-Type-Options: nosniff`](/fr/docs/Web/HTTP/Reference/Headers/X-Content-Type-Options).
