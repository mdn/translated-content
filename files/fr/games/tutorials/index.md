Cette page contient plusieurs séries de tutoriels qui mettent en évidence différents flux de travail pour créer efficacement différents types de jeux Web.

- [Jeu de casse-briques 2D utilisant JavaScript pur](/fr/docs/Games/Tutorials/2D_breakout_game_pure_JavaScript)
  - : Dans ce tutoriel étape par étape, vous allez implémenter un clone simple du jeu de casse-briques en utilisant uniquement JavaScript. En cours de route, vous apprenez les bases de l'utilisation de l'élément HTML {{HTMLElement("canvas")}} pour mettre en œuvre des mécaniques de jeu fondamentales telles que le rendu et le déplacement des images, la détection des collisions, les mécanismes de contrôle, ainsi que les états de victoire et de défaite.
- [Jeu de casse-briques 2D utilisant Phaser](/fr/docs/Games/Tutorials/2D_breakout_game_Phaser)
  - : Dans ce tutoriel étape par étape, vous allez implémenter le même clone de casse-briques que dans la série de tutoriels précédente, sauf que cette fois vous allez le faire en utilisant le cadriciel de jeu HTML [Phaser <sup>(angl.)</sup>](https://phaser.io/). L'idée ici est d'enseigner certains des fondamentaux (et des avantages) de travailler avec des cadriciels, ainsi que les mécaniques de jeu fondamentales.
- [Jeu de labyrinthe 2D utilisant l'orientation de l'appareil](/fr/docs/Games/Tutorials/HTML5_Gamedev_Phaser_Device_Orientation)
  - : Ce tutoriel montre comment créer un jeu de labyrinthe 2D en utilisant HTML, en incorporant des notions fondamentales telles que la détection des collisions et le placement des sprites sur un {{HTMLElement("canvas")}}. Il s'agit d'un jeu mobile qui utilise les **APIs** [Orientation de l'appareil](/fr/docs/Web/API/Device_orientation_events) et [Vibration](/fr/docs/Web/API/Vibration_API) pour améliorer la jouabilité et est construit en utilisant le cadriciel [Phaser <sup>(angl.)</sup>](https://phaser.io/).
- [Jeu de plateforme 2D utilisant Phaser](/fr/docs/Games/Tutorials/2D_platform_game_Phaser)
  - : Cette série de tutoriels montre comment créer un jeu de plateforme simple en utilisant le cadriciel [Phaser <sup>(angl.)</sup>](https://phaser.io/), en couvrant les notions fondamentales telles que les sprites, les collisions, la physique, les objets à collecter, et plus encore.
