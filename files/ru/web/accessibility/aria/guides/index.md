Спецификация доступные многофункциональные интернет-приложения (**Accessible Rich Internet Applications (ARIA)**) определяет способы сделать веб более доступным для людей с ограниченными возможностями. На этой странице перечислены руководства, которые вы можете использовать для улучшения доступности функций веб-страниц, таких как таблицы, формы и навигация с клавиатуры.
