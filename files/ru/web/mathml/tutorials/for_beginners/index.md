Это руководство поможет научиться создавать математические формулы с помощью структурированной разметки. Сначала в нём рассказывается, как добавить MathML в HTML-документ, а затем подробно рассматриваются основные компоненты: дроби и корни, элементы с индексами и текстовые контейнеры. После этого описываются табличная разметка для матриц и расширенное форматирование математических выражений. В завершение предлагается задание, в котором потребуется воссоздать три известные математические формулы с помощью изученных средств.

## Главы

- [Начало работы с MathML](/ru/docs/Web/MathML/Tutorials/For_beginners/Getting_started)
  - : В этой статье на примере простого HTML-документа показано, как добавить в него формулы MathML. Попутно рассматривается несколько элементов.
- [Текстовые контейнеры MathML](/ru/docs/Web/MathML/Tutorials/For_beginners/Text_containers)
  - : После знакомства с основами MathML внимание уделяется текстовым контейнерам (переменным, числам, операторам и так далее), из которых строятся формулы MathML.
- [Дроби и корни в MathML](/ru/docs/Web/MathML/Tutorials/For_beginners/Fractions_and_roots)
  - : В этой статье рассказывается, как на основе текстовых контейнеров создавать более сложные выражения MathML, вкладывая друг в друга дроби и корни.
- [Элементы MathML с индексами](/ru/docs/Web/MathML/Tutorials/For_beginners/Scripts)
  - : Продолжая знакомство с основными математическими обозначениями, эта статья посвящена созданию элементов MathML с индексами.
- [Таблицы MathML](/ru/docs/Web/MathML/Tutorials/For_beginners/Tables)
  - : После изучения основных математических обозначений остаётся рассмотреть табличную разметку, которую можно использовать для матриц и других сложных математических конструкций.
- [Задание: три известные математические формулы](/ru/docs/Web/MathML/Tutorials/For_beginners/Three_famous_mathematical_formulas)
  - : Знаний из предыдущих статей уже достаточно для записи довольно сложных формул MathML. Это задание позволит применить их на практике.
