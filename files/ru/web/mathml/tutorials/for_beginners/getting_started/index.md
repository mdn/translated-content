В этой статье на примере простого HTML-документа показано, как добавить в него формулы MathML. Попутно рассматривается несколько элементов.

## Вставка формул в HTML с помощью элемента \<math>

Для представления дерева элементов и атрибутов MathML использует тот же синтаксис, что и HTML. В частности, каждая математическая формула представляется элементом `<math>`, который можно поместить внутрь HTML-страницы. В следующем документе он находится в абзаце текста:

```html live-sample___inserting_formulas_in_HTML
<p>
  Дробь
  <math>
    <mfrac>
      <mn>1</mn>
      <mn>3</mn>
    </mfrac>
  </math>
  не является десятичной.
</p>
```

Элемент `<mfrac>` задаёт дробь с числителем (первый дочерний элемент) и знаменателем (второй дочерний элемент). Вот как она отображается в браузере:

{{ EmbedLiveSample('Inserting_formulas_in_HTML', 700, 100, "", "") }}

> [!WARNING]
> Если вместо дроби отображается только «1 3», возможно, браузер не поддерживает MathML. Дополнительную информацию можно найти в [таблице совместимости с браузерами](/ru/docs/Web/MathML/Reference/Element/math#browser_compatibility).

### Атрибут display

Обратите внимание, что в предыдущем примере формула находится в одной строке с текстом абзаца. Однако большие математические формулы часто размещают по центру на отдельной строке, как показано ниже. Для этого элементу `<math>` необходимо добавить атрибут `display="block"`.

```html hidden live-sample___the_display_attribute
<p>
  Дробь
  <math display="block">
    <mfrac>
      <mn>1</mn>
      <mn>3</mn>
    </mfrac>
  </math>
  не является десятичной.
</p>
```

{{ EmbedLiveSample('The_display_attribute', 700, 100, "", "") }}

Также можно заметить небольшое изменение внешнего вида: текст и вертикальные интервалы дроби становятся немного больше. Без атрибута `display="block"` высота сводится к минимуму, чтобы не нарушать расположение окружающего текста. При наличии атрибута `display="block"` приоритет отдаётся удобочитаемости математической формулы.

> [!NOTE]
> Это соответствует понятиям _внутристрочных_ формул (ограниченных знаками доллара `$...$`) и _выключных_ формул (ограниченных `\[...\]`) в LaTeX.

> [!NOTE]
> Описанное выше изменение внешнего вида в действительности управляется CSS-свойством {{cssxref("math-style")}}. Его исходное значение равно `normal` для `<math display="block">` и `compact` в остальных случаях. В некоторых поддеревьях MathML значение этого свойства может автоматически меняться на `compact`, но в этом руководстве такая особенность не рассматривается. В LaTeX действует схожий принцип.

## Группировка с помощью элемента \<mrow>

Элемент `<math>` может содержать произвольное количество дочерних элементов и, по сути, отображает их в строку. Например, простая формула «1 + 2 + 3» записывается на MathML следующим образом:

```html
<math>
  <mn>1</mn>
  <mo>+</mo>
  <mn>2</mn>
  <mo>+</mo>
  <mn>3</mn>
</math>
```

Элемент `<mrow>` — универсальный контейнер, который обеспечивает аналогичное расположение, но может находиться в любом месте поддерева MathML. Он помогает объединить несколько элементов в группу. Например, числителем следующей дроби (её первым дочерним элементом) является выражение «один плюс два».

```html
<math>
  <mfrac>
    <mrow>
      <mn>1</mn>
      <mo>+</mo>
      <mn>2</mn>
    </mrow>
    <mn>3</mn>
  </mfrac>
</math>
```

### Самостоятельное задание: запись вложенных выражений

В качестве упражнения попробуйте записать приведённые ниже выражения, используя только уже рассмотренные элементы MathML. Если возникнут трудности или потребуется проверить решение, изучите исходный код примера.

```html hidden live-sample___nested-expressions
<ol>
  <li>
    «одна вторая» плюс «две третьих»:
    <!-- Группировать дочерние элементы math с помощью mrow можно, но необязательно. -->
    <math>
      <mfrac>
        <mn>1</mn>
        <mn>2</mn>
      </mfrac>
      <mo>+</mo>
      <mfrac>
        <mn>2</mn>
        <mn>3</mn>
      </mfrac>
    </math>
  </li>
  <li>
    «один плюс два плюс три», делённое на «четыре плюс пять»:
    <math>
      <mfrac>
        <mrow>
          <mn>1</mn>
          <mo>+</mo>
          <mn>2</mn>
          <mo>+</mo>
          <mn>3</mn>
        </mrow>
        <mrow>
          <mn>4</mn>
          <mo>+</mo>
          <mn>5</mn>
        </mrow>
      </mfrac>
    </math>
  </li>
  <li>
    «одна четвёртая», делённая на «два плюс три»:
    <math>
      <mfrac>
        <mfrac>
          <mn>1</mn>
          <mn>4</mn>
        </mfrac>
        <mrow>
          <mn>2</mn>
          <mo>+</mo>
          <mn>3</mn>
        </mrow>
      </mfrac>
    </math>
  </li>
</ol>
```

## Итоги

В этой статье было показано, как с помощью элемента `<math>` вставить математическую формулу в HTML-документ. Были рассмотрены различия в отображении элементов `<math>` с атрибутом `display="block"` и без него. Кроме того, состоялось знакомство с несколькими другими элементами MathML: `<mfrac>` для дробей, `<mrow>` для группировки и некоторыми текстовыми элементами. Эти [текстовые контейнеры](/ru/docs/Web/MathML/Tutorials/For_beginners/Text_containers) подробнее рассматриваются в следующей статье.
