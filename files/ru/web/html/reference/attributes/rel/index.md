Атрибут **`rel`** определяет связь между ресурсом по ссылке и текущим документом. Он допустим для {{htmlelement('link')}}, {{htmlelement('a')}}, {{htmlelement('area')}} и {{htmlelement('form')}}, а поддерживаемые значения зависят от элемента, на котором задан атрибут.

Тип связи задаётся значением атрибута `rel`, которое, если оно присутствует, должно представлять собой неупорядоченный набор уникальных ключевых слов, разделённых пробелами. В отличие от имени `class`, которое не выражает семантики, атрибут `rel` должен содержать токены, семантически значимые как для машин, так и для людей. Действующими реестрами возможных значений атрибута `rel` являются [реестр отношений ссылок IANA](https://www.iana.org/assignments/link-relations/link-relations.xhtml) (англ.), [HTML Living Standard](https://html.spec.whatwg.org/multipage/links.html#linkTypes) (англ.) и свободно редактируемая [страница existing-rel-values](https://microformats.org/wiki/existing-rel-values) (англ.) в вики microformats, [как предлагает](https://html.spec.whatwg.org/multipage/links.html#other-link-types) сам Living Standard. Если использовать значение атрибута `rel`, отсутствующее в одном из трёх перечисленных выше источников, некоторые HTML-валидаторы (например, [W3C Markup Validation Service](https://validator.w3.org/) (англ.)) выдадут предупреждение.

Атрибут `rel` применим к элементам {{htmlelement('link')}}, {{htmlelement('a')}}, {{htmlelement('area')}} и {{htmlelement('form')}}, но некоторые значения относятся лишь к части из них. Как и все значения атрибутов-ключевых слов в HTML, эти значения нечувствительны к регистру.

У атрибута `rel` нет значения по умолчанию. Если атрибут опущен или ни одно из его значений не поддерживается, то у документа нет какой-либо особой связи с целевым ресурсом, кроме наличия гиперссылки между ними. В этом случае для {{htmlelement('link')}} и {{htmlelement('form')}}, если атрибут `rel` отсутствует, не содержит ключевых слов или не содержит ни одного из перечисленных выше ключевых слов, разделённых пробелами, элемент не создаёт никаких ссылок. {{htmlelement('a')}} и {{htmlelement('area')}} всё равно создадут ссылки, но без определённой связи.

## Значение

- `alternate`
  - : Указывает на альтернативное представление текущего документа. Допустимо для {{htmlelement('link')}}, {{htmlelement('a')}} и {{htmlelement('area')}}; смысл зависит от значений других атрибутов.
    - С ключевым словом [`stylesheet`](#stylesheet) на `<link>` создаёт [альтернативную таблицу стилей](/ru/docs/Web/HTML/Reference/Attributes/rel/alternate_stylesheet).

      ```html
      <!-- постоянная таблица стилей -->
      <link rel="stylesheet" href="default.css" />
      <!-- альтернативные таблицы стилей -->
      <link
        rel="alternate stylesheet"
        href="highcontrast.css"
        title="Высокая контрастность" />
      ```

    - С атрибутом [`hreflang`](/ru/docs/Web/HTML/Reference/Elements/link#hreflang), отличающимся от языка документа, указывает на перевод.
    - Со значением атрибута [`type`](/ru/docs/Web/HTML/Reference/Elements/link#type), равным `"application/rss+xml"` или `"application/atom+xml"`, создаёт гиперссылку на ленту синдикации.

      ```html
      <link
        rel="alternate"
        type="application/atom+xml"
        href="posts.xml"
        title="Блог" />
      ```

    - В остальных случаях создаёт гиперссылку на альтернативное представление текущего документа, характер которого задаётся атрибутами [`hreflang`](/ru/docs/Web/HTML/Reference/Elements/link#hreflang) и [`type`](/ru/docs/Web/HTML/Reference/Elements/link#type).
      - Если `hreflang` указан вместе с `alternate` и значение `hreflang` отличается от языка текущего документа, это означает, что документ по ссылке является переводом.
      - Если `type` указан вместе с `alternate`, это означает, что документ по ссылке представлен в альтернативном формате (например, PDF).
      - Атрибуты `hreflang` и `type` можно указывать вместе с `alternate` одновременно.

      ```html
      <link
        rel="alternate"
        href="/fr/html/print"
        hreflang="fr"
        type="text/html"
        media="print"
        title="HTML на французском (для печати)" />
      <link
        rel="alternate"
        href="/fr/pdf"
        hreflang="fr"
        type="application/pdf"
        title="PDF на французском" />
      ```

- `author`
  - : Указывает, что документ по ссылке содержит дополнительные сведения об авторе текущего документа или статьи. Актуально для элементов {{htmlelement('link')}}, {{htmlelement('a')}} и {{htmlelement('area')}}.

    Для {{htmlelement('a')}} и {{htmlelement('area')}} указывает, что документ по ссылке (или `mailto:`) содержит сведения об авторе ближайшего вышестоящего элемента {{htmlelement('article')}}, если он есть, иначе — всего документа.

    Для {{htmlelement('link')}} обозначает автора всего документа.

    > [!NOTE]
    > По историческим причинам устаревшее значение атрибута `rev="made"` обрабатывается как `rel="author"`.

- `bookmark`
  - : Актуально как значение атрибута `rel` для элементов {{htmlelement('a')}} и {{htmlelement('area')}}. Указывает постоянную ссылку на ближайший вышестоящий элемент {{htmlelement('article')}}, если он есть. Если вышестоящего элемента `<article>` нет, указывает постоянную ссылку на раздел, с которым наиболее тесно связан элемент-ссылка.
- `canonical`
  - : Допустимо для {{htmlelement('link')}}; определяет предпочтительный URL-адрес для текущего документа, что помогает поисковым системам сокращать дублирование содержимого.
- `compression-dictionary` {{experimental_inline}}
  - : Допустимо для {{htmlelement('link')}}; определяет {{glossary("Compression dictionary transport", "словарь сжатия")}}, который можно использовать для сжатия будущих загрузок ресурсов этого сайта так, чтобы их размер был меньше, чем при стандартном сжатии.
- `dns-prefetch`
  - : Актуально для элемента {{htmlelement('link')}} как в {{htmlelement('body')}}, так и в {{htmlelement('head')}}; указывает браузеру заранее выполнить DNS-разрешение для источника целевого ресурса. Полезно для ресурсов, которые, вероятно, понадобятся пользователю: помогает снизить задержку и тем самым повышает производительность при обращении к ресурсам, поскольку браузер заранее выполнил DNS-разрешение для источника указанного ресурса. Смотрите [dns-prefetch](/ru/docs/Web/Performance/Guides/dns-prefetch), описанный в [resource hints](https://w3c.github.io/resource-hints/) (англ.).
- `external`
  - : Актуально для {{htmlelement('form')}}, {{htmlelement('a')}} и {{htmlelement('area')}}; указывает, что документ по ссылке не является частью текущего сайта. Это можно использовать с селекторами атрибутов, чтобы стилизовать внешние ссылки так, чтобы пользователь понимал, что покидает текущий сайт.
- `expect` {{experimental_inline}}
  - : Позволяет заблокировать рендеринг страницы до тех пор, пока не будут разобраны основные части документа, чтобы она отображалась одинаково. Обратите внимание, что блокировка рендеринга происходит только при дополнении атрибутом [`blocking="render"`](/ru/docs/Web/HTML/Reference/Elements/link#blocking).

    > [!NOTE]
    > Подробнее о применении смотрите [Stabilizing page state to make cross-document transitions consistent](/ru/docs/Web/API/View_Transition_API/Using#stabilizing_page_state_to_make_cross-document_transitions_consistent) (англ.).

- `help`
  - : Актуально для {{htmlelement('form')}}, {{htmlelement('link')}}, {{htmlelement('a')}} и {{htmlelement('area')}}. Ключевое слово `help` указывает, что содержимое по ссылке предоставляет контекстно-зависимую справку для родителя элемента, задающего гиперссылку, и его потомков. При использовании внутри `<link>` справка относится ко всему документу. При использовании с {{htmlelement('a')}} и {{htmlelement('area')}} (если поддерживается) стандартным значением {{cssxref('cursor')}} будет `help`, а не `pointer`.
- `icon`
  - : Допустимо с {{htmlelement('link')}}; ресурс по ссылке представляет значок — ресурс для представления страницы в пользовательском интерфейсе — для текущего документа.

    Наиболее распространённое применение значения `icon` — favicon:

    ```html
    <link rel="icon" href="favicon.ico" />
    ```

    Если есть несколько `<link rel="icon">`, браузер использует их атрибуты [`media`](/ru/docs/Web/HTML/Reference/Elements/link#media), [`type`](/ru/docs/Web/HTML/Reference/Elements/link#type) и [`sizes`](/ru/docs/Web/HTML/Reference/Elements/link#sizes), чтобы выбрать наиболее подходящий значок. Если несколько значков подходят одинаково, используется последний. Если позже окажется, что самый подходящий значок непригоден (например, из-за неподдерживаемого формата), браузер переходит к следующему по пригодности и так далее.

    > [!NOTE]
    > Атрибут [`crossorigin`](/ru/docs/Web/HTML/Reference/Attributes/crossorigin) не поддерживается для `rel="icon"` в браузерах на основе Chromium. Смотрите [открытую проблему в Chromium](https://crbug.com/1121645) (англ.).

    > [!NOTE]
    > iOS от Apple не использует этот тип ссылки, как и атрибут [`sizes`](/ru/docs/Web/HTML/Reference/Elements/link#sizes), в отличие от других мобильных браузеров, для выбора значка веб-страницы для Web Clip или заставки при запуске.
    > Вместо этого он использует нестандартные [`apple-touch-icon`](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html#//apple_ref/doc/uid/TP40002051-CH3-SW4) и [`apple-touch-startup-image`](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html#//apple_ref/doc/uid/TP40002051-CH3-SW6) соответственно.

    > [!NOTE]
    > Тип ссылки `shortcut` часто встречается перед `icon`, но он не соответствует стандарту, игнорируется, и **веб-авторам больше не следует его использовать**.

- `license`
  - : Допустимо для элементов {{HTMLElement("a")}}, {{HTMLElement("area")}}, {{HTMLElement("form")}}, {{HTMLElement("link")}}. Значение `license` указывает, что гиперссылка ведёт на документ с информацией о лицензии и что основное содержимое текущего документа распространяется по лицензии, описанной в документе по ссылке. Если ссылка находится не внутри элемента {{HTMLElement("head")}}, стандарт не различает, относится ли гиперссылка к конкретной части документа или к документу целиком. На это могут указывать только данные на самой странице.

    ```html
    <link rel="license" href="#license" />
    ```

    > [!NOTE]
    > Хотя синоним `copyright` и распознаётся, он некорректен, и его следует избегать.

- `manifest`
  - : [Манифест веб-приложения](/ru/docs/Web/Progressive_web_apps/Manifest). Требует использования протокола CORS для загрузки с других источников.
- `modulepreload`
  - : Полезно для повышения производительности и актуально для {{htmlelement('link')}} в любом месте документа. Значение `rel="modulepreload"` указывает браузеру заранее загрузить скрипт (и его зависимости) и сохранить его в карте модулей документа для последующего выполнения. Ссылки `modulepreload` позволяют выполнить сетевую загрузку так, чтобы модуль был готов (но не выполнен) в карте модулей ещё до того, как он действительно понадобится. Смотрите также [`modulepreload`](/ru/docs/Web/HTML/Reference/Attributes/rel/modulepreload).
- `next`
  - : Актуально для {{htmlelement('form')}}, {{htmlelement('link')}}, {{htmlelement('a')}} и {{htmlelement('area')}}. Значение `next` указывает, что текущий документ является частью серии и что следующий документ в серии — это документ по ссылке. При использовании в `<link>` браузеры могут предположить, что этот документ будет загружен следующим, и обработать его как подсказку о ресурсе (resource hint).
- `nofollow`
  - : Актуально для {{htmlelement('form')}}, {{htmlelement('a')}} и {{htmlelement('area')}}. Ключевое слово `nofollow` указывает поисковым роботам игнорировать связь по ссылке. Отношение nofollow может означать, что владелец текущего документа не поддерживает документ по ссылке. Его часто добавляют оптимизаторы поисковых систем, выдающие свои фермы ссылок за не-спам-страницы.
- `noopener`
  - : Актуально для {{htmlelement('form')}}, {{htmlelement('a')}} и {{htmlelement('area')}}. Создаёт контекст просмотра верхнего уровня, не являющийся вспомогательным, если гиперссылка иначе создала бы один из них (то есть имеет подходящее значение атрибута `target`). Иными словами, ссылка ведёт себя так, как будто [`window.opener`](/ru/docs/Web/API/Window/opener) равен null, а `target="_parent"` задан.

    Это противоположность [`opener`](#opener).

- `noreferrer`
  - : Актуально для {{htmlelement('form')}}, {{htmlelement('a')}} и {{htmlelement('area')}}. Указание этого значения делает источник перехода неизвестным (заголовок `Referer` не отправляется) и создаёт контекст просмотра верхнего уровня, как если бы также был задан `noopener`.
- `opener`
  - : Создаёт вспомогательный контекст просмотра, если иначе гиперссылка создала бы контекст просмотра верхнего уровня, не являющийся вспомогательным (то есть имеет значение `"_blank"` атрибута `target`). По сути, противоположность [noopener](#noopener).
- `pingback`
  - : Указывает адрес pingback-сервера, обрабатывающего pingback-уведомления для текущего документа. Смотрите [спецификацию Pingback](https://www.hixie.ch/specs/pingback/pingback) (англ.).
- `preconnect`
  - : Даёт браузеру подсказку заранее открыть соединение с сайтом по ссылке, не раскрывая никакой личной информации и не загружая содержимого, чтобы при переходе по ссылке содержимое можно было загрузить быстрее.
- `prefetch`
  - : Указывает, что пользовательский агент должен заранее загрузить и кешировать целевой ресурс, так как он, вероятно, потребуется при последующем переходе.
    Подробнее смотрите {{Glossary("prefetch")}}.
- `preload`
  - : Указывает, что пользовательский агент должен заранее загрузить и кешировать целевой ресурс для текущего перехода в соответствии с потенциальным назначением, заданным атрибутом [`as`](/ru/docs/Web/HTML/Reference/Elements/link#as) (и приоритетом, связанным с этим назначением). Смотрите страницу о значении [`preload`](/ru/docs/Web/HTML/Reference/Attributes/rel/preload).
- `prerender` {{Deprecated_Inline}} {{Non-standard_Inline}}
  - : Указывает, что пользовательский агент должен заранее загрузить целевой ресурс и обработать его так, чтобы в будущем быстрее выдать ответ, например загрузив его подресурсы или выполнив часть рендеринга. Эта возможность вытеснена [Speculation Rules API](/ru/docs/Web/API/Speculation_Rules_API).
- `prev`
  - : Подобно ключевому слову [`next`](#next), актуально для {{htmlelement('form')}}, {{htmlelement('link')}}, {{htmlelement('a')}} и {{htmlelement('area')}}. Значение `prev` указывает, что текущий документ является частью серии и что ссылка ведёт на предыдущий документ в серии.

    Примечание: синоним `previous` некорректен и не должен использоваться.

- `privacy-policy`
  - : Допустимо для элементов {{htmlelement('a')}}, {{htmlelement('area')}} и {{htmlelement('link')}}. Значение `privacy-policy` указывает, что документ по ссылке является политикой конфиденциальности, описывающей практики сбора и использования данных текущего документа.

- `search`
  - : Актуально для элементов {{htmlelement('form')}}, {{htmlelement('link')}}, {{htmlelement('a')}} и {{htmlelement('area')}}. Ключевое слово `search` указывает, что гиперссылка ведёт на документ, интерфейс которого специально предназначен для поиска по текущему документу, сайту и связанным ресурсам, предоставляя ссылку на ресурс, с помощью которого можно выполнять поиск.

    Если атрибут [`type`](/ru/docs/Web/HTML/Reference/Elements/link#type) равен `application/opensearchdescription+xml`, ресурс представляет собой плагин [OpenSearch](/ru/docs/Web/XML/Guides/OpenSearch), который легко добавить в интерфейс Firefox.

- `stylesheet`
  - : Допустимо для элемента {{htmlelement('link')}}; импортирует внешний ресурс, используемый как таблица стилей. Атрибут [`type`](/ru/docs/Web/HTML/Reference/Elements/link#type) не нужен, если это таблица стилей `text/css`, поскольку это значение по умолчанию. Если таблица стилей имеет тип, отличный от `text/css`, лучше объявить тип явно.

    Хотя это значение определяет ссылку как таблицу стилей, взаимодействие с другими атрибутами и другими ключевыми словами в значении `rel` влияет на то, будет ли таблица стилей загружена и/или использована.

    При использовании с ключевым словом [`alternate`](#alternate) определяет альтернативную таблицу стилей. В этом случае укажите непустой атрибут [`title`](/ru/docs/Web/HTML/Reference/Elements/link#title).

    Внешняя таблица стилей не будет использована и даже загружена, если медиа-условие не соответствует значению атрибута [`media`](/ru/docs/Web/HTML/Reference/Elements/link#media).

    Требует использования протокола CORS для загрузки с других источников.

- `tag`
  - : Допустимо для элементов {{htmlelement('a')}} и {{htmlelement('area')}}; указывает метку (заданную указанным адресом), применимую к текущему документу. Значение `tag` означает, что ссылка ведёт на документ, описывающий метку, применимую к документу, в котором эта ссылка расположена. Этот тип ссылки не предназначен для меток в облаке тегов, поскольку такие метки применяются к группе страниц, тогда как значение `tag` атрибута `rel` относится к одному документу.

- `terms-of-service`
  - : Допустимо для элементов {{htmlelement('a')}}, {{htmlelement('area')}} и {{htmlelement('link')}}. Значение `terms-of-service` указывает, что документ по ссылке является условиями обслуживания, описывающими соглашения между поставщиком текущего документа и пользователями, желающими использовать предоставленный документ.
