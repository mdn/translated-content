このページには、MDN Web Docs から掲載終了したセクションの一覧が掲載されています。それぞれの項目には、[MDN Museum リポジトリー](https://github.com/mdn/museum) にあるアーカイブされたコンテンツへのリンクと、掲載終了の決定がなされた GitHub の issue またはディスカッションへのリンクが記載されています。

コンテンツの掲載終了方法の詳細については、[コンテンツの掲載終了](/ja/docs/MDN/Writing_guidelines/Howto/Retiring_content)のガイドを参照してください。

## 掲載終了したセクション

### Canvas レイキャスター

- **掲載終了時期:** 2022 年 6 月
- **アーカイブしたコンテンツ:** [museum/canvas-raycaster](https://github.com/mdn/museum/tree/main/canvas-raycaster)
- **GitHub の issue:** [Move canvas-raycaster into mdn/museum](https://github.com/mdn/mdn/issues/193)

Canvas API レイキャスターのデモとその関連ドキュメントページです。リポジトリーのメンテナンス作業の一環として、このコンテンツは「ミュージアム」に移動されました。

> [!NOTE]
> この掲載終了は、[コンテンツの掲載終了](/ja/docs/MDN/Writing_guidelines/Howto/Retiring_content)プロセスの作成前に実施されました。ディスカッションは残っていません。

### WebVR

- **掲載終了時期:** 2022 年 9 月
- **GitHub 上のアーカイブ:** [museum/webvr](https://github.com/mdn/museum/tree/main/webvr)
- **GitHub のプルリクエスト:** [Import webvr tests](https://github.com/mdn/museum/pull/6)

基本的な表示情報、ステージパラメーター、生の WebGL、VR コントローラーのデモ、A-Frame のデモなどを含む、WebVR API のテスト例集です。WebVR API は、[WebXR Device API](/ja/docs/Web/API/WebXR_Device_API) への移行に伴い、非推奨となりました。

> [!NOTE]
> この掲載終了は、[コンテンツの掲載終了](/ja/docs/MDN/Writing_guidelines/Howto/Retiring_content)プロセスの作成前に実施されました。ディスカッションは残っていません。

### JS フレームワーク Angular, Ember, Svelte, Vue のチュートリアル

- **掲載終了時期:** 2026 年 8 月
- **アーカイブしたコンテンツ:** [museum/learn_web_development/frameworks_libraries](https://github.com/mdn/museum/tree/main/learn_web_development/frameworks_libraries)
- **ディスカッション:** [Removing the old and out-of-date JavaScript framework articles from Learn web development](https://github.com/orgs/mdn/discussions/827)
- **GitHub のプルリクエスト:** [Archive JS framework content](https://github.com/mdn/content/pull/45105)

Angular、Ember、Svelte、Vue の各フレームワークを使用して、基本的なウェブアプリを構築する方法を示した初心者向けチュートリアルシリーズです。
