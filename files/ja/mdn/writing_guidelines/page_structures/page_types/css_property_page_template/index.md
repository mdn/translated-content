> **ページのフロントマター:**
>
> ページ上部のフロントマターは「ページのメタデータ」を定義するために使用します。

> ---
> title: name-of-the-property
> slug: Web/CSS/Reference/Properties/name-of-the-property
> l10n:
>   sourceCommit: 翻訳元コミットID
> ---

>
> - **title**
>   - : `title` の値はページの先頭に表示されます。タイトルの書式は _name-of-the-property_ です。
>     例えば、{{cssxref("background-color")}} プロパティのタイトルは _background-color_ です。
> - **slug**
>   - : `slug` の値は `https://developer.mozilla.org/ja/docs/` の後に続く URL の末尾です。これは `Web/CSS/Reference/Properties/name-of-the-property` のような形式です。
>     例えば、{{cssxref("background-color")}} プロパティのスラッグは `Web/CSS/background-color` です。スラッグ内の `Getting_started` のような複数単語の成分の場合、スラッグは `/ja/docs/Learn_web_development/Core/Structuring_content` のようにアンダースコアを使用します。
> - **sourceCommit**
>   - : （翻訳記事のみ）翻訳元の英語版記事の GitHub コミット ID を記述します。GitHub 上で英語版記事のコミット ID を確認してください。

## 構成要素のプロパティ

この節は、[animation](/ja/docs/Web/CSS/Reference/Properties/animation) のような一括指定プロパティの場合にのみ追加し、関連する個別指定プロパティをすべて列挙してください。

プロパティに応じて、次のいずれかの文で値を導入してください。

```md
このプロパティは、次の CSS プロパティの一括指定です。

このプロパティは、次の論理プロパティの一括指定です。

このプロパティは、次の物理プロパティの一括指定です。
```

### リセットのみのサブプロパティ

この節は、[animation](/ja/docs/Web/CSS/Reference/Properties/animation) のような一括指定プロパティの場合にのみ追加し、一括指定プロパティによってリセットされるものの、一括指定では設定できない個別指定プロパティをすべて列挙してください。

次の導入文を使用して、プロパティを紹介してください。

```md
このプロパティは、次の CSS プロパティを初期値にリセットします。
```

## 構文

一般的な用途をコードブロックとして記載し、完全な値を構成する成分のサブ値を記述します。

```css
/* よくある用途を示すまたは値のカテゴリーを示す */
/* コードブロックを挿入します */
```

### 値

プロパティの値の構成を伝えるために、次のいずれかのような文を記載してください。

```md
このプロパティは、次のキーワード値のいずれかで指定します。

このプロパティは、次のリストから選んだ単一の値で指定します。

このプロパティは、次の値を空白区切りのリストとして指定します。
```

この文に続けて、サブ値ごとに用語と定義を 1 つずつ含む定義リストを記載してください。値の型に対応する MDN リファレンスページがある場合は、用語にそのページへのリンクを追加してください。

- `subvalue1`
  - : サブ値の説明、データ型、何を表すかを記載します。
- `subvalue2`
  - : サブ値の説明、データ型、何を表すかを記載します。

> CSS のページには、[インライン状態マクロ](/ja/docs/MDN/Writing_guidelines/Page_structures/Feature_status#定義リスト内の機能の状態アイコン)を追加しないでください。

## 解説

この節では、プロパティについて説明し、どのように動作するかを解説してください。関連用語やプロパティの使用例もここで説明します。

プロパティが一括指定の一部である場合は、値を指定する別の方法も記載してください。

```md
`property-name` プロパティは、\{{cssxref("sibling-property")}} プロパティとともに、\{{cssxref("shorthand-property")}} 一括指定を使用して設定することもできます。
```

## 例

英語版では、例が 1 つだけのページでも、複数形の "Examples" を使用しています。

### 説明的な見出し

それぞれの例には、その例の内容を説明する H3 見出し (`###`) が必要です。見出しには例で何を行うかを具体的に記述してください。「単純な例」のような、何を示すのか分からない見出しは避けてください。見出しは簡潔にし、詳しい説明は見出しの後の段落に記載してください。ただし、最初の例が値の代入のみを示し、後により複雑な例が続く場合は、「基本的な使い方」を最初の例の見出しとして使用できます。見出しは簡潔にします。詳しい説明は見出しの後に段落として記述してください。

詳しくは、[サンプルコード](/ja/docs/MDN/Writing_guidelines/Page_structures/Code_examples)を追加する方法のガイドをご覧ください。

> [!NOTE]
> 他のページで紹介されている例にリンクしたい場合もあるでしょう。
>
> **シナリオ 1:** このページにいくつかの例があり、別のページにさらにいくつかの例がある場合。
>
> このページのそれぞれの例に H3 見出し (`###`) を記載し、最後に H3 見出し (`###`) に「その他の例」というテキストを入れ、その下に他のページの例へのリンクを貼ることができます。例えば次のようにします。
>
> ```md
> ## 例
>
> ### Fetch API の使用
>
> Fetch の例
>
> ### その他の例
>
> 他のページにある他の例へのリンク
> ```
>
> **シナリオ 2:** このページには何も例がなく、他のページに*だけ*ある場合。
>
> H3 の見出しは追加せず、H2 の見出し「例」の下に直接リンクを追加してください。例えば次のようにします。
>
> ```md
> ## 例
>
> この API の例については、[fetch() のページ](https://example.org/)を参照してください。
> ```
