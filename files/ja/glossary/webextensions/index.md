WebExtensions は Firefox でブラウザー拡張機能を開発するためのブラウザー横断のシステムです。このシステムには API が提供され、これはかなり広範に様々なブラウザー、例えば Mozilla Firefox, Google Chrome, Opera Browser, Microsoft Edge, Apple Safari に対応しています。
