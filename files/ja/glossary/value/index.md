データ、またはそのデータを包む **{{Glossary("Wrapper", "ラッパー")}} オブジェクト**の文脈では、値はそのラッパーオブジェクトに含まれる **{{Glossary("Primitive","プリミティブ値")}}** です。**{{Glossary("Variable","変数")}}** または **{{Glossary("Property","プロパティ")}}** の文脈では、値はプリミティブ値または **{{Glossary("Object reference","オブジェクト参照")}}** のいずれかです。

CSS プロパティ値の文脈では、指定値、計算値、実効値があります。各要素と擬似要素に適用される CSS プロパティの最終値は、4 段階の計算によって決まります。まず、仕様に基づいて値が決まります（[指定値](/ja/docs/Web/CSS/Guides/Cascade/Property_value_processing#指定値)）。次に、継承に使用する値へ解決され（[計算値](/ja/docs/Web/CSS/Guides/Cascade/Property_value_processing#計算値)）、必要に応じて絶対値に変換されます（[使用値](/ja/docs/Web/CSS/Guides/Cascade/Property_value_processing#使用値)）。最後に、ローカル環境の制限に応じて変換されます（[実効値](/ja/docs/Web/CSS/Guides/Cascade/Property_value_processing#実効値)）。

CSS データ型については、[CSS 値と単位](/ja/docs/Web/CSS/Guides/Values_and_units)を参照してください。
