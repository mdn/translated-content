[**CSS Object Model (CSSOM)**](/ja/docs/Web/API/CSS_Object_Model) は、文書のスタイル関連 (CSS) 情報を読み取り、変更するための一連の API です。言い換えれば、DOM が JavaScript から文書の構造やコンテンツを読み取り、変更することを可能にするのと同様に、CSSOM は JavaScript から文書のスタイルを読み取り、変更することを可能にします。
