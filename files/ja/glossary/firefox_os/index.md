Firefox OS は、Mozilla が開発した、現在は開発が終了しているオープンソースのモバイルオペレーティングシステムです。詳細については、[Firefox OS](https://ja.wikipedia.org/wiki/Firefox_OS) をご覧ください。

Firefox OS は、プロジェクトに正式名称が付けられる前は、多くの場合 Boot2Gecko とも呼ばれていました。
