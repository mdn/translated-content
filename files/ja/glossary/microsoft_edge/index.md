**Edge** は商用の、クロスプラットフォームの{{Glossary("Browser", "ブラウザー")}}で、 Microsoft が 2014 年に開発しました。Edge は、最初は Spartan として知られ、20 年以上にわたって Microsoft の主要ブラウザーであった {{glossary("Microsoft Internet Explorer", "Internet Explorer")}} を置き換えました。

Edge は Windows 10 および Windows 11 に同梱されており、macOS、iOS/iPadOS、Android、Linux でも利用できます。

Edge は 2019 年まで、{{Glossary("Engine/Rendering", "レンダリングエンジン")}}として EdgeHTML を使用していましたが、その後、{{Glossary("Google Chrome")}} で使用されているレンダリングエンジンである {{glossary("Blink")}} に置き換えました。iOS/iPadOS では、Edge は {{glossary("WebKit")}} をレンダリングエンジンとして使用しています。Edge は下位互換性のために「IE モード」に対応しており、このモードでは {{glossary("Trident")}} エンジンを使用して、古い Internet Explorer の機能が要求されるページをレンダリングします。
