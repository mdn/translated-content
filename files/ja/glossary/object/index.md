JavaScript では、オブジェクトはプロパティの集合と見なすことができます。[オブジェクトリテラル構文](/ja/docs/Web/JavaScript/Guide/Grammar_and_types#オブジェクトリテラル)を使用すると、限られたプロパティ群が初期化され、その後、プロパティを追加したり削除したりすることができます。プロパティの値は、他のオブジェクトを含め、あらゆる型の値とすることができるため、複雑なデータ構造を構築することが可能です。プロパティはキー値によって識別されます。キー値は、{{Glossary("String", "文字列値")}}または[シンボル値](/ja/docs/Web/JavaScript/Reference/Global_Objects/Symbol)のどちらかです。

オブジェクトプロパティには 2 種類があります。[データプロパティ](/ja/docs/Web/JavaScript/Guide/Data_structures#データプロパティ)と[アクセサープロパティ](/ja/docs/Web/JavaScript/Guide/Data_structures#アクセサープロパティ)です。

> [!NOTE]
> これはアクセサーのプロパティであり、アクセサーのメソッドではないことを認識しておくことが重要です。関数を値として使用することで、JavaScript オブジェクトにクラスのようなアクセサーを与えることはできますが、それによってそのオブジェクトがクラスになるわけではありません。
