**DNS** (Domain Name System) は、インターネットに接続されたリソースのための階層化された分散型の名前付けシステムです。 DNS は{{Glossary("domain name","ドメイン名")}}のリストを、それらに関連付けられた IP アドレスなどのリソースとともに管理しています。

DNS の最も顕著な機能は、人間に優しいドメイン名 (mozilla.org など) を数字の{{Glossary("IP address","IP アドレス")}} (192.0.2.172 など) に変換することです。ドメイン名を適切な IP アドレスに対応付けするこのプロセスは **DNS ルックアップ**と呼ばれています。反対に、**逆引き DNS ルックアップ** (rDNS) は、 IP アドレスに関連付けられたドメイン名を特定するために使用されます。
