CSS では**擬似クラス**セレクターを使うことで、文書ツリーからの情報ではなく、その状態によって、対象の要素を指定することができます。例えば、セレクター {{cssxref(":visited", "a:visited")}} は、ユーザーがすでに訪問したリンクだけに、スタイルを適用することができます。
