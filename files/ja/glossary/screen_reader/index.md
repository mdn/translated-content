スクリーンリーダーは、画面に表示された内容を視覚以外の方法で伝えるソフトウェアアプリケーションのことです。通常はテキストを音声に変換しますが、点字や音声アイコンに変換することもあります。スクリーンリーダーは、目の不自由な方には欠かせませんし、視覚障碍者や読み書きのできない方、学習障碍のある方にも役立ちます。ブラウザーの拡張機能を利用したスクリーンリーダーもありますが、ほとんどのスクリーンリーダーは、ブラウザーだけでなく、すべてのユーザーのアプリケーションに対してシステム全体で動作します。

ウェブアクセシビリティに関しては、ほとんどのユーザーエージェントがアクセシビリティオブジェクトモデルを提供し、スクリーンリーダーは、さまざまなオペレーティングシステムの機能を使用し、フック技術を使用して専用のアクセシビリティ API と対話します。

## 有名なスクリーンリーダー

## VoiceOver

iOS および macOS には、組み込みのスクリーンリーダーである VoiceOver が搭載されています。macOS で VoiceOver を利用するには、システム設定 > アクセシビリティ > VoiceOver の順に選択します。また、fn + Command + F5 キーを押すことで、VoiceOver のオン/オフを切り替えることもできます。VoiceOver は、コンテンツを読み上げるだけでなく、画面に表示もします。読み上げられたコンテンツは、濃い灰色のボックス内に表示されます。

VoiceOver は、コマンドショートカットと組み合わせて使用することもできます。完全な一覧については、[Mac の VoiceOver 一般コマンド](https://support.apple.com/ja-jp/guide/voiceover/cpvokys01/mac) をご覧ください。

情報については、[Mac 用 VoiceOver ユーザーガイド](https://support.apple.com/ja-jp/guide/voiceover/welcome/mac)および [iPhone のアプリで VoiceOver を使用する](https://support.apple.com/ja-jp/guide/iphone/iphe4ee74be8/ios)をご覧ください。

### Narrator

Narrator は、Windows 10 および Windows 11 に組み込まれている画面読み上げアプリケーションです。

[ナレーターの詳細なガイド](https://support.microsoft.com/ja-jp/accessibility/windows/narrator/complete-guide-to-narrator)をご覧ください。

### ChromeVox

Chromebook には ChromeVox というスクリーンリーダーが組み込まれており、これにより視覚障碍のある人も Chrome OS を使用することができます。

詳しくは[ChromeVox スクリーンリーダー](https://support.google.com/accessibility/answer/7031755)をご覧ください。
