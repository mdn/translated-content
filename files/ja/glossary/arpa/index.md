**.arpa** (address and routing parameter area) はインターネットインフラ関連の目的で使われる{{glossary("TLD","トップレベルドメイン")}}です。特に DNS 逆引き（{{glossary("IP address", "IP アドレス")}}から{{glossary("domain name","ドメイン名")}}を調べること）のために使われます。

この名称は、**ARPA**（現在は [DARPA](https://en.wikipedia.org/wiki/DARPA)、すなわち国防高等研究計画局として知られる）に由来しています。DARPA は、インターネット ({{glossary("ARPANET")}}) や GPS、人工知能、仮想現実の先駆けとなる技術を開発するに貢献したとされています。このドメインは当初、ARPANET のコンピューターに体系的な名称を付与するための一時的な機能としてのみ意図されていたが、インフラとしての利用が承認された後も除去されませんでした。その結果、ARPA というドメイン名は "Address and Routing Parameter Area"（アドレスおよびルーティングパラメータ領域）のバックロニムとなっています。

{{glossary("TLD")}} は、DARPA がまだ ARPA と呼ばれていた時点で同機関で設計されたものであり、そのためドメイン名が `.arpa` となっている。

最も代表的な `.arpa` ドメインには、それぞれ IPv4 アドレスおよび IPv6 アドレスの逆引き DNS 検索用の名前空間を提供する `in-addr.arpa` および `ip6.arpa` を含みます。
