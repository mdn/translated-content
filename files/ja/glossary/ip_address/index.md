**IP アドレス**は、IP ネットワークでそれぞれの端末を固有に挿すために使用される番号です。

IP は「インターネットプロトコル」の略で、このアドレスが関連付けられている[プロトコル層](https://docs.oracle.com/cd/E19683-01/806-4075/ipov-7/index.html)です。

「IP アドレス」は IPv6 がもっと広がっていくまでは、典型的にはまだ 32 ビットの IPv4 アドレスを参照します。
