**実ユーザーモニタリング** (**RUM**) は、実ユーザーのマシンからページのパフォーマンスを測定します。通常、サードパーティーのスクリプトが各ページに注入され、行われたすべてのリクエストについてページ読み込みのデータを測定して報告します。この技術は、アプリケーションの実際のユーザー操作を監視します。RUM では、サードパーティーのスクリプトが実ユーザーのブラウザーからパフォーマンス指標を収集します。RUM は、ユーザーの地理的分布やその分布がエンドユーザーの体験に与える影響を含め、アプリケーションの使用方法を特定するのに役立ちます。
