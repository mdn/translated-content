Thunderbird 向けの拡張機能も、Firefox の拡張機能と同じ方法でコーディングできます。テキストエディターや好みのツールを使ってコードを書きます。

## API の違い

> [!NOTE]
> Thunderbird 固有の WebExtension API については、[ReadTheDocs](https://webextension-api.thunderbird.net/en/latest/) のドキュメントを参照してください。

どちらも Gecko ベースなので、Thunderbird は Firefox にある API の多くに対応していますが、いくつか違いがあります。詳しくは [manifest.json のブラウザーの互換性](/ja/docs/Mozilla/Add-ons/WebExtensions/manifest.json#ブラウザーの互換性)と [JavaScript API 群のブラウザーの互換性](/ja/docs/Mozilla/Add-ons/WebExtensions/Browser_support_for_JavaScript_APIs)を参照してください。
