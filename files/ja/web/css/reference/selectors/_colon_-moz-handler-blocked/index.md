**`:-moz-handler-blocked`** は [CSS](/ja/docs/Web/CSS) の[擬似クラス](/ja/docs/Web/CSS/Reference/Selectors/Pseudo-classes)で、ハンドラーがブロックされているために表示できない要素に一致する [Mozilla 拡張](/ja/docs/Web/CSS/Reference/Mozilla_extensions)です。

> [!NOTE]
> このセレクターは、主にテーマ開発者が使用するためのものです。

## 構文

```css
:-moz-handler-blocked {
  /* ... */
}
```

## 仕様書

どの仕様にも含まれていません。
