**`chOff`** は {{domxref("HTMLTableCellElement")}} インターフェイスのプロパティで、何もしません。これは、このセル要素の `charoff` 属性を反映します。

> [!NOTE]
> このプロパティは、表のセルのコンテンツを特定の文字（通常は小数点）で揃えて配置できるようにするために設計されましたが、ブラウザーで実装されることはありませんでした。
>
> このような配置を実現するには、CSS の {{cssxref("text-align")}} プロパティによる文字列値の対応状況を確認してください。

## 値

整数です。
