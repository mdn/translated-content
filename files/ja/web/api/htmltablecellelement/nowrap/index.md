{{APIRef("HTML DOM API")}}{{deprecated_header}}

**`noWrap`** は {{domxref("HTMLTableCellElement")}} インターフェイスのプロパティで、セルのテキストが複数行にまたがって表示されるかどうかを示す論理値を返します。

> [!NOTE]
> このプロパティは非推奨となっています。代わりに、CSS の {{cssxref("white-space")}} プロパティに値 `nowrap` を指定して使用すべきです。

## 値

論理値です。

## 例

代わりに CSS の `white-space` を使用してください。[例](/ja/docs/Web/CSS/Reference/Properties/white-space#controlling_line_wrapping_in_tables)が {{cssxref("white-space")}} ページにあります。
