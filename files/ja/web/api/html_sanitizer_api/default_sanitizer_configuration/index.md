{{DefaultAPISidebar("HTML Sanitizer API")}}

デフォルトの無害化設定は、`configuration` を引数として渡さなかった場合に [`Sanitizer()` コンストラクター](/ja/docs/Web/API/Sanitizer/Sanitizer)が返す構成を定義します。
この同じ構成は、カスタム無害化オブジェクトを指定せずに {{domxref("Element.setHTML()")}}、{{domxref("ShadowRoot.setHTML()")}}、{{domxref("Document.parseHTML_static","Document.parseHTML()")}} などの[安全な無害化メソッド](/ja/docs/Web/API/HTML_Sanitizer_API#無害化メソッド)を呼び出した場合にも暗黙的に使用されます。

この構成は、次の種類の項目を除去します。

1. XSS に対して安全でないことが分かっている項目:
   - {{htmlelement("base")}}、{{htmlelement("embed")}}、{{htmlelement("frame")}}、{{htmlelement("iframe")}}、{{htmlelement("object")}}、{{htmlelement("script")}}、{{SVGElement("use")}}。
   - `onafterprint`、`onbeforeinput` など、すべてのイベントハンドラーコンテンツ属性。
2. クリックジャッキング、なりすまし、その他の攻撃に使用される可能性がある項目。
3. 非推奨の項目。
4. コメントと `data-*` 属性。

そのため、攻撃対象領域を最小限に抑えつつ、大部分の無害化の用途に適した無害化オブジェクトを提供します。

> [!NOTE]
> {{domxref("Sanitizer.removeUnsafe()")}} を呼び出した場合や、安全な無害化メソッドにカスタム無害化オブジェクトを渡した場合は、XSS に対して安全でない項目だけが除去されます。
> 追加の項目、コメント、`data-*` 属性は除去されません。

以下の節ではすべての要素を一覧表示し、デフォルトの構成で _許可_ される要素に &check; マークを付けています（したがって、❌ は除去される要素を示します）。
「追加で許可される属性」列には、対応する要素で許可される属性を記載しています。要素にあるその他の属性は、グローバル属性で許可されていない限り除去されます。
[グローバル属性](#グローバル属性)の節には、すべての要素で許可される属性（構成の使用時に除去されない属性）を一覧表示しています。
