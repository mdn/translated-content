**`Window.captureEvents()`** メソッドは何もしません。その元の動作は仕様から削除されていますが、このメソッド自体はそれを呼び出すコードを壊さないために残されています。

## 構文

```js-nolint
captureEvents()
```

### 引数

なし。

### 返値

なし ({{jsxref("undefined")}}).
