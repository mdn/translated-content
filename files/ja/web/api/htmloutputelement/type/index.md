{{ApiRef("HTML DOM")}}

**`type`** は {{domxref("HTMLOutputElement")}} インターフェイスの読み取り専用プロパティで、文字列 `"output"` を返します。

## 値

文字列 `"output"` です。

## 例

```js
const output = document.querySelector("output");
console.log(output.type); // "output"
```
