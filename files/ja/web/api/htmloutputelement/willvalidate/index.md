{{APIRef("HTML DOM")}}

**`willValidate`** は {{domxref("HTMLOutputElement")}} インターフェイスの読み取り専用プロパティで、`false` を返します。{{HTMLElement("output")}} 要素は[制約検証](/ja/docs/Web/HTML/Guides/Constraint_validation)の対象ではないためです。

## 値

論理値 `false` です。
