{{APIRef("HTML DOM")}}

**`form`** は {{domxref("HTMLOutputElement")}} インターフェイスの読み取り専用プロパティで、この {{htmlelement("output")}} を所有する {{domxref("HTMLFormElement")}} オブジェクトを返します。この出力がどのフォームにも所有されていない場合は、`null` を返します。

## 値

{{domxref("HTMLFormElement")}} または `null` です。
