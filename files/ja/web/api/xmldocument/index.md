**XMLDocument** インターフェイスは XML 文書を示します。汎用的な {{DOMxRef("Document")}} を継承し、固有のメソッドやプロパティを追加しません。それでもこれら 2 種類の文書では、いくつかのアルゴリズムの動作が異なります。
