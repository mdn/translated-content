`set:distinct()` は指定されたノード集合のうち、文字列値が一意であるノードだけを含む部分集合を返します。

## 構文

```plain
set:distinct(nodeSet)
```

### 引数

- `nodeSet`
  - : 一意な文字列値を持つノードを探す対象のノード集合です。

### 返値

文字列値が一意であるノードからなるノード集合です。
