このガイドでは、ウェブ上で音声や動画をストリーミングする技術と、可能な限り高い品質とパフォーマンスを実現するために、ストリーミングに使用するコード、メディア、サーバー、設定を最適化する方法を説明します。

## プロトコル

サーバーとストリーミングコードの設定に加えて、パフォーマンスを最適化するために使用できる特別なプロトコルが存在することがあります。

### HTTP ライブストリーミング

**HTTP ライブストリーミング** (**HLS**) は Apple が開発したプロトコルで、Safari はすべてのプラットフォームでこれに対応しています。ほかの環境でも対応している場合がありますが、条件付きの場合もあります。

例えば、多くのウェブサイトのモバイル専用コンテンツは、モバイルブラウザーが HLS に対応していることを前提としています。この前提が当てはまらない場合に予期しない互換性エラーが起きないよう、Android 版 Firefox も HLS に対応しています。ただし、デスクトップ版 Firefox は HLS に対応していません。

HLS ではプレイリストを利用して、ストリーミングするメディアだけでなく、同じメディアのバージョンや形式も選択できます。例えば、複数の音声ストリームを含む動画を配信し、ユーザーが自分の言語の音声を選択できるようにできます。また、異なるネットワーク条件に最適化したストリーム形式も提供できます。このように、ライブストリームを柔軟にし、高いパフォーマンスを実現できます。

2017 年半ば現在、HLS は {{RFC(8216)}} として標準化されています。
