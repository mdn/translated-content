**`amplitude`** 属性は、成分転送要素の {{SVGAttr("type")}} 属性が `gamma` の場合、そのガンマ関数の振幅を制御します。

この属性は以下の SVG 要素で使用できます。

- {{SVGElement("feFuncA")}}
- {{SVGElement("feFuncB")}}
- {{SVGElement("feFuncG")}}
- {{SVGElement("feFuncR")}}
