この章では、ウェブのエコシステムとその仕組みに関する一般的な質問を扱います。

- [インターネットの仕組み](/ja/docs/Learn_web_development/Howto/Web_mechanics/How_does_the_Internet_work)
  - : **インターネット**はウェブの基盤であり、ウェブを実現する技術的なインフラです。
    ごく基本的には、インターネットは互いに通信するコンピューターからなる巨大なネットワークです。この記事では、その仕組みを大まかに説明します。
- [ウェブページ、ウェブサイト、ウェブサーバー、検索エンジンの違いは？](/ja/docs/Learn_web_development/Getting_started/Environment_setup/Browsing_the_web)
  - : この記事では、ウェブページ、ウェブサイト、ウェブサーバー、検索エンジンなど、ウェブに関するさまざまな概念を説明します。これらの用語は、ウェブ初心者にとって混乱の原因になったり、誤って使われたりすることがよくあります。それぞれが実際に何を意味するのか見ていきましょう。
- [ハイパーリンクとは](/ja/docs/Learn_web_development/Howto/Web_mechanics/What_are_hyperlinks)
  - : この記事では、ハイパーリンクがどのようなもので、なぜ大切なのかを説明しています。
- [URL とは](/ja/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_URL)
  - : URL は、{{Glossary("Hypertext", "ハイパーテキスト")}}や {{Glossary("HTTP")}} とともに、インターネットの重要な概念です。URL は、{{Glossary("Browser","ブラウザー")}}がウェブ上で公開されているあらゆるリソースを取得するために使う仕組みです。
- [ドメイン名とは](/ja/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_domain_name)
  - : ドメイン名はインターネットインフラの重要な構成要素です。インターネット上で利用できるあらゆるウェブサーバーに、人間が読み取れるアドレスを提供します。
- [ウェブサーバーとは](/ja/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_web_server)
  - : 「ウェブサーバー」という言葉は、ウェブ上でクライアントにウェブサイトを配信するハードウェアやソフトウェア、またはその両方を指します。この記事では、ウェブサーバーの仕組みと重要性を説明します。
