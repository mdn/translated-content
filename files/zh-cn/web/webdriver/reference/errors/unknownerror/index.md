**unknown** 错误是一种 [WebDriver 错误](/zh-CN/docs/Web/WebDriver/Reference/Errors)，当驱动程序在处理[命令](/zh-CN/docs/Web/WebDriver/Reference/Classic/Commands)时发生未指明的错误时会出现。

unknown 错误通常特定于某个驱动程序，因此最好阅读错误消息（如有），以了解发生了什么。
