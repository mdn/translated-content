**WebDriver classic** 是最初的 WebDriver 协议，提供基于 HTTP 的浏览器自动化命令。本参考说明了 WebDriver classic 中可用的命令和超时。

- [命令](/zh-CN/docs/Web/WebDriver/Reference/Classic/Commands)
  - : 基于 HTTP 的操作，用于检查并控制浏览器行为、管理浏览器会话和窗口，以及与 DOM 元素交互。
- [超时](/zh-CN/docs/Web/WebDriver/Reference/Classic/Timeouts)
  - : 控制脚本注入、文档导航和元素获取行为的超时定义。
