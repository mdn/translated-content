**`DOMRect()`** 构造函数创建一个新的 {{domxref("DOMRect")}} 对象。

## 语法

```js-nolint
new DOMRect(x, y, width, height)
```

### 参数

- {{domxref("DOMRect.x", "x")}}
  - : `DOMRect` 原点的 x 坐标。
- {{domxref("DOMRect.y", "y")}}
  - : `DOMRect` 原点的 y 坐标。
- {{domxref("DOMRect.width", "width")}}
  - : `DOMRect` 的宽度。
- {{domxref("DOMRect.height", "height")}}
  - : `DOMRect` 的高度。

### 返回值

一个新的 {{domxref("DOMRect")}} 对象。
