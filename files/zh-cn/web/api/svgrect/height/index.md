{{APIRef("SVG")}}

{{domxref("SVGRect")}} 接口的 **`height`** 属性是 {{DOMXref("DOMRect.height")}} 属性的别名。它描述元素的垂直尺寸。它反映 SVG 元素的 {{SVGattr("height")}} 属性和 CSS {{cssxref("height")}} 属性。

该高度是一个长度；它是用户坐标系中从元素顶部到元素底部的距离。其语法与 [`<length>`](/zh-CN/docs/Web/SVG/Guides/Content_type#长度) 相同。
