{{APIRef("SVG")}}

{{domxref("SVGRect")}} 接口的 **`width`** 属性是 {{DOMXref("DOMRect.width")}} 属性的别名。它描述元素的水平尺寸。它反映 SVG 元素的 {{SVGattr("width")}} 属性和 CSS {{cssxref("width")}} 属性。

该宽度是一个长度；它是用户坐标系中从元素左侧到元素右侧的距离。其语法与 [`<length>`](/zh-CN/docs/Web/SVG/Guides/Content_type#长度) 相同。
