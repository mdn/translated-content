{{APIRef("HTML DOM")}}

{{domxref("HTMLMediaElement")}} 接口的 **`pause()`** 方法会暂停媒体播放。如果媒体已经处于暂停状态，此方法没有任何效果。

## 语法

```js-nolint
pause()
```

### 参数

无。

### 返回值

无（{{jsxref("undefined")}}）。

### 异常

无。
