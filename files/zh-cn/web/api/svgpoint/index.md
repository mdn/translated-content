{{APIRef("SVG")}}

**`SVGPoint`** 表示 SVG 坐标系统中的一个二维或三维点。在 SVG 2 中，它已被 {{domxref("DOMPoint")}} 和 {{domxref("DOMPointReadOnly")}} 取代。所有原先返回 `SVGPoint` 的 API（包括 {{domxref("SVGSVGElement.createSVGPoint()")}}）现在都改为返回 {{domxref("DOMPoint")}}。
